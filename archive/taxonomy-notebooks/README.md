# Archived taxonomy notebooks

These notebooks and their partial helper module are historical references. Supported extraction, validation and installation now live in `backend/taxonomy_pipeline`; see [the workflow documentation](../../docs/taxonomy-pipeline.md).

The original files are preserved without rewriting their cells or outputs. Machine-specific paths and notebook package discovery are not used by the application or build. Parity tests execute only the unified notebook's definition cell on isolated real Arelle fixture models. Full 2026 FRC extraction was also compared against the existing outputs; historical display-label differences are documented and the new candidate was not activated.
